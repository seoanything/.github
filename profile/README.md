# SEOAnything

An SEO and AI search toolkit for site owners, writers and developers.

- **Website:** https://www.seoanything.dev/
- **Free tools, no account needed:** https://www.seoanything.dev/tools
- **Docs:** https://www.seoanything.dev/docs
- **CLI:** `npx seoanything-cli` ([npm](https://www.npmjs.com/package/seoanything-cli))

It shows what people search on Google today in 15 markets, finds keyword suggestions from Google, YouTube and DuckDuckGo, crawls your site against 70 rules with read-only Search Console data, checks whether AI search crawlers can read your pages, and turns a finding into a post in its blog studio. It also runs as a REST API and a remote MCP server for AI editors.
